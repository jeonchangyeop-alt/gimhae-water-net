# 김해시 상수도 관망관리 시스템 (1단계 프로토타입)

본 시스템은 **김해시 상수도 관망 데이터(VWorld GIS)를 시각화**하고, **현장에서 시설물을 선택하여 속성을 수정하거나 조사를 수행**하며, **사진을 초경량으로 자동 압축하여 보관·전송**할 수 있는 현장 조사 & PC 관제 통합 솔루션입니다.

---

## 🚀 빠른 실행 방법

1. 폴더 내의 **`start_server.bat`** 파일을 마우스로 **더블클릭**합니다.
2. 로컬 서버가 시작되며 기본 웹 브라우저가 자동으로 열립니다.
   - 주소: `http://localhost:8080/index.html`

---

## 💡 1단계 탑재 핵심 기능

1. **VWorld 국가공간정보 배경지도:**
   - [일반지도] 및 [항공위성] 원클릭 전환
   - 김해시청 및 부원동 일대 관망 공간 뷰
2. **관망 시설물 시각화 및 선택:**
   - 관로(Pipes): 관경(D50~D300)별 가변 선 굵기 및 색상 표현
   - 제수변(Valves): 기어 마커 아이콘 및 회전수/상태 툴팁
   - 계량기(Meters): 수용가 및 최근 지침값 마커
3. **선택 기반 현장조사 & 속성 수정:**
   - 지도나 목록에서 시설물을 클릭하면 좌측 패널에 상세 정보 표출
   - `[기본정보 수정]`을 통해 관경, 주소 등 현장 실측치로 갱신 가능
   - 시설물 유형별 맞춤 입력란 (수압, 지침, 회전수, 누수의심 등)
4. **초경량 사진 자동 압축 엔진 (무료 클라우드 최적화):**
   - 일반 사진: 긴 변 최대 1920px 리사이징 + WebP 0.8 압축 (장당 100~250KB 수준으로 80~95% 용량 절감)
   - 명판/지침 고화질 모드 선택 가능
   - 작은 이미지는 확대하지 않는 비확대 원칙 준수
   - 목록용 200px 썸네일 동시 생성
5. **오프라인 우선 영속 저장 (IndexedDB):**
   - 창을 닫거나 컴퓨터가 꺼져도 작성한 조사 내역과 사진이 100% 보존
   - `[동기화]` 버튼: 클라우드 서버 저장 상태 시뮬레이션
   - `[NAS 백업]` 버튼: 조사 데이터 및 수정 내역을 JSON 파일로 즉시 다운로드
